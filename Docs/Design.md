# GlassReader Design Notes

## Product Positioning

GlassReader 是一款专注本地内容的轻量 macOS 阅读器。它把图片、PDF 和漫画压缩包统一为页面序列，并强调快速打开、连续阅读和对漫画阅读习惯的支持。

## Existing Interaction Model

- 用户可以通过菜单、打开面板、拖放或系统“打开方式”载入内容。
- 左侧栏集合了文件入口、阅读显示设置、收藏与历史记录。
- 顶部标签栏允许同时打开多个来源并切换。
- 阅读区支持单页和双页、从左到右和从右到左、跨页重新匹配以及多种适配方式。
- 鼠标、触控板、键盘快捷键、缩略图与底部进度条均可用于导航。
- 全屏、专注和沉浸模式用于减少界面干扰；覆盖控件可按当前模式显示或隐藏。
- 收藏、历史、阅读位置、布局和标签页状态可在会话之间恢复；隐私浏览模式不记录历史。
- 密码压缩包使用模态提示，并支持嵌套归档继续请求密码。

## Existing UI Principles

- 内容是视觉中心，控制区域使用半透明材质、紧凑间距和系统符号。
- 在普通、专注、全屏与沉浸状态之间保持一致的阅读行为。
- 使用 macOS 原生窗口、菜单、文件面板和拖放习惯。
- 阅读方向与页面组合显式可控，避免替用户猜测漫画装订方式。
- 错误和空状态尽量在当前阅读上下文内表达。
